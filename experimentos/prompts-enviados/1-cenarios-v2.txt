Atue como um engenheiro de QA especialista em testes de integração de APIs REST.

## Contexto
O serviço de Pedidos (Java 21, Spring Boot 3.5.16, JUnit 5, AssertJ e WireMock 3.13) faz o checkout em
POST /pedidos: consulta o preço de cada item na API de Estoque, reserva os itens, cobra na API de Pagamentos e
confirma ou desfaz a reserva. Estoque e Pagamentos são APIs de outros times. Os contratos OpenAPI, as regras de
integração (R1 a R12), a classe base de testes e o código do serviço estão anexados.

## Escopo deste prompt
Só os fluxos de negócio entre os três serviços: caminho feliz com PIX e com cartão, vários itens e quantidades,
pedido com total zero, produto inexistente (na consulta e na reserva), sem estoque, pagamento recusado, validação
de entrada (R1) e consulta do pedido gravado (R12). Falhas de rede, timeouts, retentativas e contrato ficam para
outros prompts: não gere testes para eles. No máximo 15 cenários, priorizando os que exercitam regras diferentes.

## As regras são a fonte da verdade
Cada expectativa vem das regras e dos contratos, não do código. Se o código contradisser uma regra, escreva o teste
pela regra e aponte a divergência no fim.

## Infraestrutura (use exatamente esta)
- A classe de teste estende IntegracaoBase (anexada): o serviço sobe de verdade em porta aleatória e Estoque e
  Pagamentos são os WireMockServer estáticos ESTOQUE e PAGAMENTOS. Não crie WireMock, @RegisterExtension,
  @DynamicPropertySource nem contexto próprio, e não use @Nested.
- Chame o serviço por HTTP com postarPedido(json) e consultarPedido(id). Não use Mockito nem @MockitoBean.
- Os stubs devem responder como o provedor real: use os exemplos e todos os campos obrigatórios dos contratos.

## Em cada teste, verifique três coisas
1. o status HTTP e os campos do corpo que a regra define (status, motivo, totalCentavos, pagamentoId);
2. as chamadas feitas a ESTOQUE e PAGAMENTOS: quantidade, corpo (ex.: valorCentavos e itens da reserva) e headers
   (Idempotency-Key);
3. o que não pode ter sido chamado (ex.: cobrança quando falta estoque, confirmação quando o pagamento é recusado).

## Formato da resposta
1. Tabela de cenários: ID, regra(s), stubs (o que Estoque e Pagamentos respondem), requisição, resultado esperado e
   interações verificadas.
2. Uma classe CheckoutFluxosIT (pacote com.estudo.checkout.fluxos) estendendo IntegracaoBase, um @Test por cenário,
   @DisplayName com ID e regra, no padrão Arrange/Act/Assert.
3. Divergências entre o código e as regras, se houver.

````markdown
# Regras de integração do checkout

Especificação do que o serviço de Pedidos deve fazer em POST /pedidos ao conversar com as APIs de Estoque e
Pagamentos. Os contratos das duas APIs estão em [`contratos/`](../contratos).

```mermaid
sequenceDiagram
    autonumber
    participant C as Cliente (front-end)
    participant P as Serviço de Pedidos
    participant E as API de Estoque
    participant G as API de Pagamentos
    C->>P: POST /pedidos
    loop para cada item
        P->>E: GET /produtos/{sku}
        E-->>P: 200 {precoCentavos}
    end
    P->>E: POST /reservas {pedidoId, itens}
    E-->>P: 201 {id}
    P->>G: POST /pagamentos (Idempotency-Key: pedido-{id})
    G-->>P: 201 {status: APROVADO}
    P->>E: POST /reservas/{id}/confirmacao
    P-->>C: 201 CONFIRMADO
    Note over P,G: RECUSADO: DELETE /reservas/{id} e 402<br/>timeout ou 5xx: até 3 tentativas com a mesma chave, depois DELETE /reservas/{id} e 503
```

| Regra | Descrição |
|-------|-----------|
| **R1** Validação de entrada | `clienteId` obrigatório; de 1 a 20 itens; `sku` não vazio; `quantidade` de 1 a 99; `metodoPagamento` PIX ou CARTAO; `tokenCartao` obrigatório quando CARTAO. Entrada inválida: **400** `DADOS_INVALIDOS`, sem nenhuma chamada ao Estoque ou ao Pagamentos e sem gravar pedido. |
| **R2** Preço vem do Estoque | Para cada item, `GET /produtos/{sku}`. Total = soma de `precoCentavos` x `quantidade`. O cliente não informa preço. |
| **R3** Produto inexistente | 404 do Estoque (na consulta ou na reserva): **422** `PRODUTO_INEXISTENTE`. Nada é reservado nem cobrado. |
| **R4** Reserva antes da cobrança | `POST /reservas` com o `pedidoId` e todos os itens. 409 do Estoque: **409** `SEM_ESTOQUE`, e o Pagamentos não é chamado. |
| **R5** Cobrança | `POST /pagamentos` com `valorCentavos` igual ao total do pedido, `metodo`, `tokenCartao` só quando CARTAO (com PIX o token é descartado) e o header `Idempotency-Key: pedido-{id do pedido}`. Pedido com total 0 (só itens gratuitos) não é cobrado, porque o Pagamentos exige `valorCentavos >= 1`: segue direto para a confirmação (R7). |
| **R6** Retentativa | Timeout, conexão recusada/resetada ou HTTP 5xx do Pagamentos: até **3 tentativas** no total, todas com a **mesma** Idempotency-Key. HTTP 4xx não é repetido. |
| **R7** Pagamento aprovado | Pagamento aprovado ou pedido com total 0: `POST /reservas/{id}/confirmacao` e **201** `CONFIRMADO`. |
| **R8** Pagamento recusado | Compensação: `DELETE /reservas/{id}`. **402** `PAGAMENTO_RECUSADO`, com o `motivo` informado pelo Pagamentos. |
| **R9** Pagamentos com falha | Indisponível depois das tentativas, resposta 4xx ou resposta fora do contrato (ex.: sem `id` ou `status`): `DELETE /reservas/{id}` e **503** `FALHA_INTEGRACAO`. Indisponibilidade nunca é tratada como recusa. |
| **R10** Estoque com falha | Timeout, falha de conexão, HTTP 5xx ou resposta fora do contrato (`precoCentavos` ausente, negativo ou com casa decimal; reserva sem `id`): **503** `FALHA_INTEGRACAO`, sem chamar o Pagamentos. A reserva não é repetida automaticamente (não é idempotente). |
| **R11** Falha depois da cobrança | Falha ao confirmar a reserva depois do pagamento aprovado: o pedido continua **201** `CONFIRMADO` (a pendência vai para o log). Falha ao liberar a reserva: o status do pedido não muda (a reserva expira sozinha no Estoque em 15 minutos). |
| **R12** Consulta | Todo pedido que passa pela validação é gravado com o status final e pode ser consultado em `GET /pedidos/{id}` (404 se não existir). O `motivo` de `FALHA_INTEGRACAO` começa com o nome do serviço (`estoque: ...` ou `pagamentos: ...`). |
````

### src/test/java/com/estudo/checkout/suporte/IntegracaoBase.java
```java
package com.estudo.checkout.suporte;

import com.fasterxml.jackson.databind.JsonNode;
import com.github.tomakehurst.wiremock.WireMockServer;
import org.junit.jupiter.api.BeforeEach;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.test.web.client.TestRestTemplate;
import org.springframework.http.HttpEntity;
import org.springframework.http.HttpHeaders;
import org.springframework.http.MediaType;
import org.springframework.http.ResponseEntity;
import org.springframework.test.context.DynamicPropertyRegistry;
import org.springframework.test.context.DynamicPropertySource;

import static com.github.tomakehurst.wiremock.core.WireMockConfiguration.options;

/**
 * Base dos testes de integração: sobe o serviço de Pedidos de verdade (Spring Boot em porta aleatória, chamado por
 * HTTP) e simula as APIs de Estoque e Pagamentos com WireMock, também em portas reais. Só as APIs externas são
 * simuladas: controller, service e clients HTTP rodam como em produção.
 * <p>
 * Os dois WireMock sobem uma vez e ficam de pé até o fim da execução, para que todas as classes de teste
 * compartilhem o mesmo contexto do Spring (as URLs não mudam). Antes de cada teste, stubs e histórico são zerados.
 */
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
public abstract class IntegracaoBase {

    /** Timeout dos clients nos testes: curto, para os cenários de lentidão não demorarem. */
    protected static final int TIMEOUT_MS = 400;

    protected static final WireMockServer ESTOQUE = new WireMockServer(options().dynamicPort());
    protected static final WireMockServer PAGAMENTOS = new WireMockServer(options().dynamicPort());

    static {
        ESTOQUE.start();
        PAGAMENTOS.start();
    }

    @DynamicPropertySource
    static void apontarParaOsSimuladores(DynamicPropertyRegistry registry) {
        registry.add("servicos.estoque.url", ESTOQUE::baseUrl);
        registry.add("servicos.pagamentos.url", PAGAMENTOS::baseUrl);
        registry.add("servicos.estoque.timeout-ms", () -> TIMEOUT_MS);
        registry.add("servicos.pagamentos.timeout-ms", () -> TIMEOUT_MS);
        registry.add("servicos.pagamentos.max-tentativas", () -> 3);
    }

    @Autowired
    protected TestRestTemplate api;

    @BeforeEach
    void zerarSimuladores() {
        ESTOQUE.resetAll();
        PAGAMENTOS.resetAll();
    }

    /** POST /pedidos com o corpo JSON informado. Respostas 4xx e 5xx não lançam exceção. */
    protected ResponseEntity<JsonNode> postarPedido(String corpoJson) {
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);
        return api.postForEntity("/pedidos", new HttpEntity<>(corpoJson, headers), JsonNode.class);
    }

    protected ResponseEntity<JsonNode> consultarPedido(String id) {
        return api.getForEntity("/pedidos/{id}", JsonNode.class, id);
    }
}
```

### src/main/java/com/estudo/checkout/pedido/PedidoService.java
```java
package com.estudo.checkout.pedido;

import com.estudo.checkout.integracao.FalhaIntegracaoException;
import com.estudo.checkout.integracao.estoque.ContratoEstoque;
import com.estudo.checkout.integracao.estoque.EstoqueClient;
import com.estudo.checkout.integracao.estoque.EstoqueInsuficienteException;
import com.estudo.checkout.integracao.estoque.ProdutoInexistenteException;
import com.estudo.checkout.integracao.pagamentos.ContratoPagamentos;
import com.estudo.checkout.integracao.pagamentos.PagamentosClient;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class PedidoService {

    private static final Logger log = LoggerFactory.getLogger(PedidoService.class);

    private final EstoqueClient estoqueClient;
    private final PagamentosClient pagamentosClient;
    private final PedidoRepository pedidoRepository;

    public PedidoService(EstoqueClient estoqueClient, PagamentosClient pagamentosClient,
                         PedidoRepository pedidoRepository) {
        this.estoqueClient = estoqueClient;
        this.pagamentosClient = pagamentosClient;
        this.pedidoRepository = pedidoRepository;
    }

    /**
     * Checkout: consulta o preço de cada item no Estoque, reserva os itens, cobra no Pagamentos e confirma a reserva.
     * <p>
     * O pedido é gravado com o status que representa o resultado (ver {@link StatusPedido}). Quando a cobrança não
     * acontece, por recusa ou por falha de integração, a reserva é desfeita para devolver os itens ao estoque.
     */
    public Pedido criar(NovoPedidoRequest requisicao) {
        List<ItemPedido> itens = requisicao.itens().stream()
                .map(item -> new ItemPedido(item.sku(), item.quantidade()))
                .toList();
        Pedido pedido = new Pedido(requisicao.clienteId(), itens, requisicao.metodoPagamento());
        try {
            precificar(pedido);
            reservar(pedido);
            cobrar(pedido, requisicao.tokenCartao());
        } catch (ProdutoInexistenteException e) {
            pedido.finalizar(StatusPedido.PRODUTO_INEXISTENTE, e.getMessage());
        } catch (EstoqueInsuficienteException e) {
            pedido.finalizar(StatusPedido.SEM_ESTOQUE, e.getMessage());
        } catch (FalhaIntegracaoException e) {
            desfazerReserva(pedido);
            pedido.finalizar(StatusPedido.FALHA_INTEGRACAO, e.getMessage());
        }
        return pedidoRepository.salvar(pedido);
    }

    /** O preço vem sempre do Estoque: o cliente não informa preço no pedido. */
    private void precificar(Pedido pedido) {
        for (ItemPedido item : pedido.getItens()) {
            ContratoEstoque.Produto produto = estoqueClient.consultarProduto(item.getSku());
            item.definirPrecoUnitario(produto.precoCentavos());
        }
    }

    private void reservar(Pedido pedido) {
        List<ContratoEstoque.ItemReserva> itens = pedido.getItens().stream()
                .map(item -> new ContratoEstoque.ItemReserva(item.getSku(), item.getQuantidade()))
                .toList();
        ContratoEstoque.Reserva reserva = estoqueClient.reservar(pedido.getId(), itens);
        pedido.registrarReserva(reserva.id());
    }

    private void cobrar(Pedido pedido, String tokenCartao) {
        // Pedido só com itens gratuitos não passa pelo Pagamentos, que exige valorCentavos >= 1.
        if (pedido.getTotalCentavos() > 0) {
            // O contrato do Pagamentos não aceita tokenCartao em pagamento PIX.
            String tokenDoPagamento = pedido.getMetodoPagamento() == MetodoPagamento.CARTAO ? tokenCartao : null;
            ContratoPagamentos.Pagamento pagamento = pagamentosClient.autorizar(
                    pedido.getId(), pedido.getTotalCentavos(), pedido.getMetodoPagamento().name(), tokenDoPagamento);
            pedido.registrarPagamento(pagamento.id());
            if (pagamento.status() != ContratoPagamentos.StatusPagamento.APROVADO) {
                desfazerReserva(pedido);
                pedido.finalizar(StatusPedido.PAGAMENTO_RECUSADO, pagamento.motivo());
                return;
            }
        }
        confirmarReserva(pedido);
        pedido.finalizar(StatusPedido.CONFIRMADO, null);
    }

    /** O pagamento já foi aprovado, então uma falha aqui não cancela o pedido: a confirmação fica pendente. */
    private void confirmarReserva(Pedido pedido) {
        try {
            estoqueClient.confirmar(pedido.getReservaId());
        } catch (FalhaIntegracaoException e) {
            log.error("Pedido {} pago, mas a confirmação da reserva {} ficou pendente: {}",
                    pedido.getId(), pedido.getReservaId(), e.getMessage());
        }
    }

    /**
     * Compensação: devolve ao estoque os itens reservados de um pedido que não vai ser cobrado.
     * Se a liberação falhar, a reserva expira sozinha no Estoque (15 minutos, pelo contrato), então só registramos o erro.
     */
    private void desfazerReserva(Pedido pedido) {
        if (pedido.getReservaId() == null) {
            return;
        }
        try {
            estoqueClient.liberar(pedido.getReservaId());
        } catch (FalhaIntegracaoException e) {
            log.error("Não foi possível liberar a reserva {} do pedido {}: {}",
                    pedido.getReservaId(), pedido.getId(), e.getMessage());
        }
    }
}
```

```java
package com.estudo.checkout.pedido;

import java.util.List;
import java.util.UUID;

public class Pedido {

    private final String id = UUID.randomUUID().toString();
    private final String clienteId;
    private final List<ItemPedido> itens;
    private final MetodoPagamento metodoPagamento;
    private StatusPedido status;
    private String motivo;
    private String reservaId;
    private String pagamentoId;

    public Pedido(String clienteId, List<ItemPedido> itens, MetodoPagamento metodoPagamento) {
        this.clienteId = clienteId;
        this.itens = List.copyOf(itens);
        this.metodoPagamento = metodoPagamento;
    }

    /** Soma de preço unitário x quantidade, ou {@code null} enquanto algum item ainda não tem preço. */
    public Long getTotalCentavos() {
        long totalCentavos = 0;
        for (ItemPedido item : itens) {
            if (item.getPrecoUnitarioCentavos() == null) {
                return null;
            }
            totalCentavos += item.getPrecoUnitarioCentavos() * item.getQuantidade();
        }
        return totalCentavos;
    }

    void registrarReserva(String reservaId) {
        this.reservaId = reservaId;
    }

    void registrarPagamento(String pagamentoId) {
        this.pagamentoId = pagamentoId;
    }

    void finalizar(StatusPedido status, String motivo) {
        this.status = status;
        this.motivo = motivo;
    }

    public String getId() {
        return id;
    }

    public String getClienteId() {
        return clienteId;
    }

    public List<ItemPedido> getItens() {
        return itens;
    }

    public MetodoPagamento getMetodoPagamento() {
        return metodoPagamento;
    }

    public StatusPedido getStatus() {
        return status;
    }

    public String getMotivo() {
        return motivo;
    }

    public String getReservaId() {
```

```java
    FALHA_INTEGRACAO(HttpStatus.SERVICE_UNAVAILABLE);

    private final HttpStatus statusHttp;

    StatusPedido(HttpStatus statusHttp) {
        this.statusHttp = statusHttp;
    }

    public HttpStatus getStatusHttp() {
        return statusHttp;
```

```java
import org.springframework.http.ResponseEntity;

import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.List;

/** Entrada inválida é rejeitada com 400 antes de qualquer chamada ao Estoque ou ao Pagamentos. */
@RestControllerAdvice
public class TratadorDeErros {

    public record ErroResponse(String codigo, List<String> detalhes) {
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErroResponse> dadosInvalidos(MethodArgumentNotValidException e) {

                .map(erro -> erro instanceof FieldError campo
                        ? campo.getField() + ": " + campo.getDefaultMessage()
                        : erro.getDefaultMessage())
                .toList();
        return ResponseEntity.badRequest().body(new ErroResponse("DADOS_INVALIDOS", detalhes));
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    public ResponseEntity<ErroResponse> corpoIlegivel(HttpMessageNotReadableException e) {
        return ResponseEntity.badRequest()
                .body(new ErroResponse("DADOS_INVALIDOS", List.of("corpo da requisição ausente ou com formato inválido")));
    }
```

```java
package com.estudo.checkout.integracao;

import org.springframework.http.client.JdkClientHttpRequestFactory;
import org.springframework.web.client.RestClient;

import java.net.http.HttpClient;
import java.time.Duration;

public final class FabricaRestClient {

    private FabricaRestClient() {
    }

    /**
     * Cria um RestClient com URL base e timeout de conexão e de leitura.
     * Usa o HttpClient do JDK porque o HttpURLConnection pode repetir um POST por conta própria em algumas falhas de
     * rede, o que atrapalharia o controle de tentativas feito pelos clients.
     */
    public static RestClient criar(RestClient.Builder builder, String urlBase, Duration timeout) {
        HttpClient httpClient = HttpClient.newBuilder()
                .version(HttpClient.Version.HTTP_1_1)
                .connectTimeout(timeout)
                .build();
        JdkClientHttpRequestFactory requestFactory = new JdkClientHttpRequestFactory(httpClient);
        requestFactory.setReadTimeout(timeout);
        return builder.baseUrl(urlBase).requestFactory(requestFactory).build();
    }
}
```

```java
package com.estudo.checkout.integracao.estoque;

import com.estudo.checkout.integracao.FabricaRestClient;
import com.estudo.checkout.integracao.FalhaIntegracaoException;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;
import org.springframework.web.client.HttpClientErrorException;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.RestClientException;

import java.time.Duration;
import java.util.List;

/** Client da API de Estoque. As chamadas não são repetidas: a reserva não é idempotente. */
@Component
public class EstoqueClient {

    private static final String SERVICO = "estoque";

    private final RestClient restClient;

    public EstoqueClient(RestClient.Builder builder,
                         @Value("${servicos.estoque.url}") String url,
                         @Value("${servicos.estoque.timeout-ms}") long timeoutMs) {
        this.restClient = FabricaRestClient.criar(builder, url, Duration.ofMillis(timeoutMs));
    }

    public ContratoEstoque.Produto consultarProduto(String sku) {
        ContratoEstoque.Produto produto;
        try {
            produto = restClient.get()
                    .uri("/produtos/{sku}", sku)
                    .retrieve()
                    .body(ContratoEstoque.Produto.class);
        } catch (HttpClientErrorException.NotFound e) {
            throw new ProdutoInexistenteException(sku);
        } catch (RestClientException e) {
            throw new FalhaIntegracaoException(SERVICO, "erro em GET /produtos/" + sku, e);
        }
        if (produto == null || produto.precoCentavos() == null || produto.precoCentavos() < 0) {
            throw new FalhaIntegracaoException(SERVICO, "resposta de GET /produtos/" + sku + " fora do contrato");
        }
        return produto;
    }

    public ContratoEstoque.Reserva reservar(String pedidoId, List<ContratoEstoque.ItemReserva> itens) {
        ContratoEstoque.Reserva reserva;
        try {
            reserva = restClient.post()
                    .uri("/reservas")
                    .body(new ContratoEstoque.NovaReserva(pedidoId, itens))
                    .retrieve()
                    .body(ContratoEstoque.Reserva.class);
        } catch (HttpClientErrorException.Conflict e) {
            ContratoEstoque.Erro erro = lerErro(e);
            throw new EstoqueInsuficienteException(erro.sku(), erro.disponivel());
        } catch (HttpClientErrorException.NotFound e) {
            throw new ProdutoInexistenteException(lerErro(e).sku());
        } catch (RestClientException e) {
            throw new FalhaIntegracaoException(SERVICO, "erro em POST /reservas", e);
        }
        if (reserva == null || reserva.id() == null) {
            throw new FalhaIntegracaoException(SERVICO, "resposta de POST /reservas fora do contrato");
        }
        return reserva;
    }

    public void confirmar(String reservaId) {
        try {
            restClient.post()
                    .uri("/reservas/{id}/confirmacao", reservaId)
                    .retrieve()
                    .toBodilessEntity();
        } catch (RestClientException e) {
            throw new FalhaIntegracaoException(SERVICO, "erro em POST /reservas/" + reservaId + "/confirmacao", e);
        }
    }

    public void liberar(String reservaId) {
        try {
            restClient.delete()
                    .uri("/reservas/{id}", reservaId)
                    .retrieve()
                    .toBodilessEntity();
        } catch (RestClientException e) {
            throw new FalhaIntegracaoException(SERVICO, "erro em DELETE /reservas/" + reservaId, e);
        }
    }

    /** Um corpo de erro ilegível não pode esconder o motivo do 404/409, por isso cai num erro sem detalhes. */
    private ContratoEstoque.Erro lerErro(HttpClientErrorException e) {
        try {
            ContratoEstoque.Erro erro = e.getResponseBodyAs(ContratoEstoque.Erro.class);
            return erro != null ? erro : new ContratoEstoque.Erro(null, null, null, null);
        } catch (RuntimeException corpoIlegivel) {
            return new ContratoEstoque.Erro(null, null, null, null);
        }
    }
}
```

```java
package com.estudo.checkout.integracao.pagamentos;

import com.estudo.checkout.integracao.FabricaRestClient;
import com.estudo.checkout.integracao.FalhaIntegracaoException;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;
import org.springframework.web.client.HttpServerErrorException;
import org.springframework.web.client.ResourceAccessException;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.RestClientException;

import java.time.Duration;

@Component
public class PagamentosClient {

    private static final Logger log = LoggerFactory.getLogger(PagamentosClient.class);
    private static final String SERVICO = "pagamentos";

    private final RestClient restClient;
    private final int maxTentativas;

    public PagamentosClient(RestClient.Builder builder,
                            @Value("${servicos.pagamentos.url}") String url,
                            @Value("${servicos.pagamentos.timeout-ms}") long timeoutMs,
                            @Value("${servicos.pagamentos.max-tentativas}") int maxTentativas) {
        this.restClient = FabricaRestClient.criar(builder, url, Duration.ofMillis(timeoutMs));
        this.maxTentativas = maxTentativas;
    }

    /**
     * Pede a autorização do pagamento de um pedido.
     * <p>
     * Timeout, falha de conexão e HTTP 5xx são falhas transitórias: a chamada é repetida até {@code maxTentativas}
     * vezes, sempre com a mesma Idempotency-Key. Assim, se uma tentativa chegou a ser processada e só a resposta se
     * perdeu, a API de Pagamentos devolve a cobrança original em vez de cobrar de novo. HTTP 4xx não é repetido,
     * porque a próxima tentativa receberia a mesma resposta.
     *
     * @throws FalhaIntegracaoException quando as tentativas acabam, quando a API responde 4xx ou quando a resposta
     *                                  está fora do contrato
     */
    public ContratoPagamentos.Pagamento autorizar(String pedidoId, long valorCentavos, String metodo, String tokenCartao) {
        ContratoPagamentos.NovoPagamento novoPagamento =
                new ContratoPagamentos.NovoPagamento(pedidoId, valorCentavos, metodo, tokenCartao);
        RestClientException ultimaFalha = null;
        for (int tentativa = 1; tentativa <= maxTentativas; tentativa++) {
            try {
                ContratoPagamentos.Pagamento pagamento = restClient.post()
                        .uri("/pagamentos")
                        .header("Idempotency-Key", chaveIdempotencia(pedidoId))
                        .body(novoPagamento)
                        .retrieve()
                        .body(ContratoPagamentos.Pagamento.class);
                return validarContrato(pagamento);
            } catch (HttpServerErrorException | ResourceAccessException e) {
                ultimaFalha = e;
                log.warn("Tentativa {}/{} de pagamento do pedido {} falhou: {}",
                        tentativa, maxTentativas, pedidoId, e.getMessage());
            } catch (RestClientException e) {
                throw new FalhaIntegracaoException(SERVICO, "erro não transitório em POST /pagamentos", e);
            }
        }
        throw new FalhaIntegracaoException(SERVICO, "indisponível após " + maxTentativas + " tentativas", ultimaFalha);
    }

    /** A chave depende só do pedido, para que todas as tentativas de cobrar o mesmo pedido contem como uma só. */
    private String chaveIdempotencia(String pedidoId) {
        return "pedido-" + pedidoId;
    }

    private ContratoPagamentos.Pagamento validarContrato(ContratoPagamentos.Pagamento pagamento) {
        if (pagamento == null || pagamento.id() == null || pagamento.status() == null) {
            throw new FalhaIntegracaoException(SERVICO, "resposta de POST /pagamentos fora do contrato");
        }
        return pagamento;
    }
}
```

```java
package com.estudo.checkout.integracao.pagamentos;

import com.fasterxml.jackson.annotation.JsonInclude;

/**
 * Mensagens da API de Pagamentos (contratos/pagamentos-api.yaml) do ponto de vista do serviço de Pedidos: só os
 * campos que ele envia ou lê. Campos a mais na resposta são ignorados.
 */
public final class ContratoPagamentos {

    private ContratoPagamentos() {
    }

    public enum StatusPagamento {
        APROVADO,
        RECUSADO
    }

    /** tokenCartao só vai no JSON quando existe: no contrato ele é opcional e não aceita null. */
    @JsonInclude(JsonInclude.Include.NON_NULL)
    public record NovoPagamento(String pedidoId, long valorCentavos, String metodo, String tokenCartao) {
    }

    public record Pagamento(String id, StatusPagamento status, String motivo) {
    }
}
```
